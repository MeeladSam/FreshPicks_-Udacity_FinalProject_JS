# 🍓 FreshPicks - Fresh Fruit Market

A simple fruit store shopping cart project built with vanilla HTML, CSS, and JavaScript.

<a href="https://meeladsam.github.io/FreshPicks_-Udacity_FinalProject_JS/">Live Demo</a>

## 📸 Preview

> A fresh, modern fruit market where users can browse products, manage their cart, and complete purchases.

## 🚀 Features

- 🛒 Add / Remove products from cart
- ➕➖ Increase or decrease item quantity
- 💰 Real-time cart total calculation
- 💳 Cash payment with change calculation
- 🔃 Sort products by price (Low to High / High to Low)
- 🗑️ Clear entire cart
- 📱 Responsive layout

## 🛠️ How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/MeeladSam/freshpicks.git
   ```

2. Open `src/index.html` in your browser — or use **Live Server** in VS Code for best results.

> ⚠️ Opening directly with `file://` may cause issues loading scripts. Use Live Server instead.

## 🧪 Running Tests

```bash
npm install
npm run test
```

Tests cover: `addProductToCart`, `increaseQuantity`, `decreaseQuantity`, `removeProductFromCart`, `cartTotal`, `pay`, and `emptyCart`.
